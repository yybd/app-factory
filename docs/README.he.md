# docs

שלושה סוגי מסמכים, וההבדל ביניהם הוא מי קורא אותם ומתי.

## [`contracts/`](contracts) — מה משהו חייב להכיל

קוראים אותם כשמקימים דבר, או כשסקיל אומר שהוא לא מוצא משהו. כל אחד מתאר מבנה
שסקילים נשענים עליו, ולכל אחד יש סקריפט שיוצר את מה שהוא מתאר.

| | | |
|---|---|---|
| [hub.he.md](contracts/hub.he.md) | ריפו נתונים שכמה אפליקציות חולקות: פרופילים, טקסט לחנות, מדיה, מחירים | `factory/init_hub.py` |
| [keys.he.md](contracts/keys.he.md) | תיקיית האישורים, ומה הסקילים עושים ולא עושים איתה | `factory/init_keys.py` |
| [site.he.md](contracts/site.he.md) | מה החנויות באמת צריכות מאתר, שזו כתובת אחת שנפתחת | `factory/check_urls.py` |

**שלושתם אופציונליים.** כל סקיל שיכול להשתמש בהאב עובד בלעדיו; סטודיו בלי אתר עדיין
שולח, כל עוד כתובת הפרטיות שהוא נותן לחנויות נפתחת.

## [`decisions/`](decisions) — למה משהו הוא כמו שהוא

**לא הוראות.** אלה רשומות: מה הוחלט, מה נמדד כדי להכריע, ומה נדחה ועל סמך מה. כמה
מההחלטות נראות שגויות במבט ראשון, ובלי הרשומה הן נשאלות מחדש כל כמה שבועות ונענות
מאפס. **מה שחוסך את הזמן הוא לעיתים רחוקות ההחלטה — זו החלופה שנפסלה.**

הן מתוארכות, והן מתארות את המצב באותו רגע. רשומת החלטה שסותרת את הקוד של היום אינה
באג ברשומה.

|---|---|

| [2 — מה נדרש כדי לשלוח את זה כמוצר](decisions/2-product-readiness.he.md) | הערכת המוכנות, ומה היא מצאה כחוסם |
