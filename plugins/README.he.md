# הפלאגינים — שישה מסלולים של סקילים, ואחד שעושה התקנה

**מה התיקייה הזו.** סקילי האפליקציות, מופצים כתוספים מה‑marketplace של ה‑repo הזה
(`app-factory`). תיקייה אחת לכל מסלול.

| מסלול | סקילים | מה |
|---|---|---|
| `apple-track` | 16 | App Store והפצה ישירה ב‑macOS |
| `android-track` | 9 | Google Play |
| `shared-track` | 7 | חוצה‑חנויות — פרופיל, מחירים, שחרור, קופי |
| `web-track` | 4 | אתרים |
| `capacitor-track` | 2 | אפליקציות Capacitor |
| `design-track` | 1 | עיצוב ו‑frontend |
| `factory-setup` | 1 | התקנה, וזה שדולק בכל מקום |
| **סך הכל** | **40** | |

*נספר מהדיסק 2026-09-11.*

---

## שתי עובדות שמכריעות את כל השאר

**1. אילו repos טוענים איזה מסלול נקבע ברישום**, דרך ה‑`.claude/settings.json` של כל
repo. הרישום הוא של grove, ו‑`python3 factory/deploy.py` הוא מה שהופך אותו לקבצים האלה.

**2. מה שנטען אינו התיקייה הזו — אלא תצלום שלה.** ההתקנה העתיקה את הסקילים ל‑
`~/.claude/plugins/cache/app-factory/<track>/<version>/`, וכל סשן קורא מהעותק. עריכה
כאן אינה מגיעה לשם מעצמה: פורסים, ואז **פותחים סשן חדש**.

**שם התיקייה הוא הגרסה, לא הקומיט** — ולכן `claude plugin update` הוא no-op בין
שחרורים, כמה שהתוכן לא ישתנה. זה מה שהופך את הקפצת הגרסה לדבר שמגיע למישהו, וזו
הסיבה ש-`factory/deploy.py` מתקין מחדש במקום לעדכן כשההשוואה בייט-בייט אומרת
שהעותק עדיין ישן.

## איך תוסף באמת מגיע לסשן

המנגנון הזה — שני הרישומים, למה גרסאות ישנות נשארות תחת
`.in_use/`, מה נכנס לקונטקסט של סשן ומה לא, שני המסלולים להדלקת מסלול גלובלית, והמעקה
שמבחין שהעותק וה‑repo נפרדו — הוא נושא אחד, והוא מתועד פעם אחת, ב**grove**:
ב‑`plugins/README.he.md` שלו. grove הוא שמחזיק את הפריסה ומשלח את המעקה; לתאר את זה
שוב כאן היה נותן שני תיאורים לדבר אחד, שמתפצלים.

**מה ששייך ל‑repo הזה** הוא מה שהמסלולים האלה מכילים, איזה מסלול repo צריך לשאת,
וההכרעות מאחורי שניהם:

* **[SKILLS.he.md](../SKILLS.he.md)** — כל מסלול וכל סקיל, ואיפה כל אחד נטען.
* **[docs/decisions/](../docs/decisions/)** — למה האב והאתר אינם "פרויקט אחד".
* **[../HOW-IT-WORKS.he.md](../HOW-IT-WORKS.he.md)** — הגרסה הקצרה של מסלול הטעינה.

## פקודות

```bash
python3 factory/deploy.py        # הרישום → ההגדרות, ה‑repo → העותקים, אימות
claude plugin list               # מה מותקן, ובאיזו גרסה
claude plugin details apple-track   # מלאי ועלות טוקנים
```

בכל מקרה — **לפתוח סשן חדש** כדי שהעדכון ייכנס לתוקף.
